# Talon

### What is Talon?
Talon is a remake of the, currently RoturAPI stuck, forum server, [Claw](https://github.com/RoturTW/api/blob/main/handlers_posts.go). Claw has all functionality one would expect: Message posting, editing, and deleting, replies, likes, and some other cool stuff. It's very close to like a Twitter or BSky feed is a thing to note.
### Who is Talon?
Talon is made by me, any contributors on the repo, Mist (who originally made Claw which this is basically an API clone of) and a few other people for helping me figure out the API and making edits to my API understanding doc for Claw. 
### Why is Talon? (Wait that doesn't sound right...)
Talon exists for three reasons. 1: Open-sourcing Claw and making it not part of the RoturAPI. 2: Adding features that never existed before in Claw. 3: I'm so bored I might hang myself.
### Final Thoughts
There are docs in docs.md, I strongly encourage everyone, **add to this.** Make pull requests, unique clients, host your own servers, this is here for an easily hostable and edtiable method to a forum type server.
